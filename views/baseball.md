# 野球選手名鑑の設計

## 対象と目的
野球の打者を対象とする。
選手一覧から選手を選び、指定年度の個人成績を確認できるようにする。
選手1人につき、1年度分のデータを登録する。

## 画面とページ遷移
- `/players` で選手名・所属チーム・守備位置を一覧表示する。
- 選手名をクリックすると `/players/0` などの詳細画面に移動する。
- 詳細画面で年度・出場試合数・打率・本塁打数・打点を表示する。
- 「選手一覧に戻る」リンクで一覧画面に戻る。

URL末尾の番号は、授業の駅一覧と同じく配列の位置を表す。
最初の選手は0とする。

## データ構造（スキーマ）
データはJavaScriptの配列で管理し、各選手をオブジェクトとして格納する。

| 項目名 | 内容 | 型 |
|---|---|---|
| id | 選手ID | 数値 |
| name | 選手名 | 文字列 |
| team | 所属チーム | 文字列 |
| position | 守備位置 | 文字列 |
| year | 成績の年度 | 数値 |
| games | 出場試合数 | 数値 |
| average | 打率 | 数値 |
| homeRuns | 本塁打数 | 数値 |
| rbi | 打点 | 数値 |

## 今後実装する機能
REST APIを使い、選手データの一覧表示・詳細表示・追加・削除・変更を行う。
