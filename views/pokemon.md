# ポケモン歴代ゲーム作品一覧の設計

## 対象と目的
歴代のポケットモンスターのゲーム作品を管理する。
作品一覧から作品を選び、その特徴を確認できるようにする。

## 画面とページ遷移
- `/pokemon` で作品名・発売年・対応機種を一覧表示する。
- 作品名をクリックすると `/pokemon/0` などの詳細画面に移動する。
- 詳細画面で舞台の地方・最初に選べるポケモン・特徴・感想を表示する。
- 「作品一覧に戻る」リンクで一覧画面に戻る。

URL末尾の番号は配列の位置を表し、最初の作品は0とする。

## データ構造（スキーマ）
データはJavaScriptの配列で管理する。

| 項目名 | 内容 | 型 |
|---|---|---|
| id | 作品ID | 数値 |
| title | 作品名 | 文字列 |
| releaseYear | 発売年 | 数値 |
| platform | 対応機種 | 文字列 |
| region | 舞台の地方 | 文字列 |
| starters | 最初に選べるポケモン | 文字列 |
| features | 作品の特徴 | 文字列 |
| comment | 自分の感想 | 文字列 |

## 今後実装する機能
REST APIを使い、作品データの一覧表示・詳細表示・追加・削除・変更を行う。
