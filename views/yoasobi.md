# YOASOBI楽曲リストの設計

## 対象と目的
YOASOBIの楽曲情報を管理する。
楽曲一覧から曲を選び、曲の情報や自分の感想を確認できるようにする。

## 画面とページ遷移
- `/yoasobi` で曲名・発売日を一覧表示する。
- 曲名をクリックすると `/yoasobi/0` などの詳細画面に移動する。
- 詳細画面で収録作品・曲の長さ・原作・感想を表示する。
- 「楽曲一覧に戻る」リンクで一覧画面に戻る。

URL末尾の番号は配列の位置を表し、最初の楽曲は0とする。

## データ構造（スキーマ）
データはJavaScriptの配列で管理し、各楽曲をオブジェクトとして格納する。

| 項目名 | 内容 | 型 |
|---|---|---|
| id | 楽曲ID | 数値 |
| title | 曲名 | 文字列 |
| releaseDate | 発売日 | 文字列 |
| album | 収録作品 | 文字列 |
| duration | 曲の長さ | 文字列 |
| originalWork | 原作 | 文字列 |
| comment | 自分の感想 | 文字列 |

## 今後実装する機能
REST APIを使い、楽曲データの一覧表示・詳細表示・追加・削除・変更を行う。
